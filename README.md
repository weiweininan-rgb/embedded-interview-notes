# 嵌入式项目技术复习笔记

这是三个嵌入式项目的技术复习资料发布版，包含适合长期查阅的机制说明、架构分析、源码、示例代码和选型权衡。

## 内容

- `天气时钟/cards/`：STM32、通信协议、DMA、FreeRTOS、消息队列、任务通知与显示链路。
- `数码相框/cards/`：Linux 文件 I/O、FrameBuffer、图像解码、FreeType、input event、tslib 与模块化设计。
- `S参数/cards/`：交叉编译、IQ/S 参数算法、FFT、线程队列、TCP 协议、字符设备、设备树与内核裁剪。
- `source/`：天气时钟 STM32 工程源码、数码相框本机可获得的实验源码，以及 S 参数模拟系统的用户态、驱动、Qt、测试和工具代码。

## 发布边界

仓库不包含固件、构建产物、真实密钥、本机网络配置、本机绝对路径、真实硬件映射、个人面试记录或详细学习进度。源码中的 Wi-Fi、天气 API 与目标主机配置均已替换为占位符或本地回环地址；完整数码相框课程案例源码不在本机资料中。
