# 嵌入式项目技术复习笔记

这是三个嵌入式项目的技术复习资料发布版，只保留适合长期查阅的机制说明、架构分析、示例代码和选型权衡。

## 内容

- `天气时钟/cards/`：STM32、通信协议、DMA、FreeRTOS、消息队列、任务通知与显示链路。
- `数码相框/cards/`：Linux 文件 I/O、FrameBuffer、图像解码、FreeType、input event、tslib 与模块化设计。
- `S参数/cards/`：交叉编译、IQ/S 参数算法、FFT、线程队列、TCP 协议、字符设备、设备树与内核裁剪。

## 发布边界

仓库不包含项目源码、固件、构建产物、密钥、网络配置、本机绝对路径、真实硬件映射、个人面试记录或详细学习进度。示例代码用于解释技术机制，不代表可直接编译部署的完整工程。
